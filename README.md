# superlucky84/tap

Homebrew tap for superlucky84's apps.

## portwatch

Menu bar app that lists local dev servers and stops them through their manager.
Apple Silicon, macOS 15 or later.

```sh
brew install --cask superlucky84/tap/portwatch
```

The app is ad-hoc signed and not notarized. On first launch macOS blocks it:
open System Settings → Privacy & Security and choose **Open Anyway**.

Update with `brew upgrade --cask portwatch`, remove with `brew uninstall --cask portwatch`.
